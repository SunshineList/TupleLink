- 实际导入 1000 节点订阅，手动节点列表仍保持原来的 7 个；订阅末页、全量

  浏览器模拟，详情抽屉覆盖完整面板宽度。

## 测速链路

- 不再把全部节点放进一个同步请求。前端去重后每批最多 8 个，逐批更新缓存、
  显示进度，并支持本批完成后停止；每个手动节点和订阅节点均有独立测速。
- 后端限制每请求最多 8 个节点，并限制同时只运行一批；提前解析检查目标，
  单节点 12 秒、整批 24 秒预算，传递 GraphQL 请求的取消上下文。超过批量
  限制的旧客户端会收到明确错误，须分批调用。LuCI 网关原 30 秒限制保留。
- `nodeLatencies` 只读取缓存和运行时结果，不再隐式探测全部节点；合并时采用
  较新的结果。网关错误显示简短提示，不显示原始 GraphQL 请求和响应。
- 5 项新增 Go 测试包含真实 SOCKS/HTTP 延迟、执行中取消、并发/期限、查询不
  发起探测、批量限制和结果顺序。原生 LuCI CGI → GraphQL → 实际后端一次
  测试 8 个本地 SOCKS 节点，全部获得延迟；随后的缓存查询没有增加代理请求。
- 浏览器故障注入覆盖单节点 ID、100 节点分批、进度、停止、502 与已有结果
  保留；故障注入测试与真实探测分别验证，未使用真实订阅凭据或外部代理。

## 构建、升级与范围

- 前端 31 项测试、TypeScript、ESLint；71 项 OpenWrt 隔离测试无跳过，8 项
  LuCI 脚本测试、4 项 Go 网关测试、原有订阅传输和 BTF 测试均通过。
- 从实际 0.4.0 程序升级到 0.5.0，10 张用户数据表摘要、API 资源、节点、
  订阅、群组正则绑定与面板偏好一致；无数据库迁移或网络配置变更。
- x86_64 / ARM64 静态程序、22 个原生 IPK/APK；验证架构、依赖、权限、
  安装脚本和 GeoSite/GeoIP 路径。最终 x86_64 IPK 中的程序用于原生 LuCI
  浏览器回归。R4S `aarch64_generic` APK 通过官方索引 HTTP 仓库依赖模拟。

代理启停仅做故障注入，真实程序以 API-only 模式运行，未加载宿主 eBPF 或改动

# 0.3.2 验证记录

日期：2026-10-18；分支：`codex/openwrt-plugin`。

## GeoSite / GeoIP 路径衔接

用户点击启动代理时，后端报告在 `/etc/daed`、XDG 和 `/usr/share/daed` 找不到
`geosite.dat`。固定 dae 源码的 `LocationFinder` 与固件 geodata 包安装定义确认：
默认搜索目录按应用名取 `daed`，而规则文件实际装在 `/usr/share/v2ray`。

运行包新增两条指向该目录的相对符号链接，保持 `/etc/daed` 自定义规则优先级；
没有覆盖、复制或修改其他代理的规则库。安装器检查安装后的规则可读性，预检
在缺失时给出警告，允许首次安装获取依赖。两种包格式均核对链接目标与包所有权。

验证结果：

- 用 dae 的真实 `LocationFinder`、protobuf 读取器和 `DatReaderOptimizer`，
  在隔离 OpenWrt rootfs 中复现原报错，随后用最终 IPK 中的链接修复并解析。
- 另下载 OpenWrt 25.12.5 / aarch64_generic 官方规则包，核验 APK 格式并解包，
  得到相同的修复前失败；修复后展开 6,624 条域名规则和 15,365 条 IP 规则。
  规则包版本：GeoSite 20261009101206-r1、GeoIP 202610050438-r1。
- 61 项 Python 测试全部通过，新增 5 项检查：路径错误复现、规则展开、自定义
  数据优先且不改写、依赖缺失预警、安装后缺规则不启动。原安装、备份、APK
  架构、会话及订阅测试保留；ShellCheck、8 项 LuCI 脚本测试与工作区测试通过。
- x86_64 / ARM64 程序与 22 个原生 IPK/APK；每包核对 GeoSite/GeoIP 相对链接，
  并校验元数据、程序架构、权限和脚本。R4S 使用 `aarch64_generic` APK。
- 最终 IPK 原生 LuCI / rpcd / uhttpd 升级回归保留数据及订阅 SOCKS 测试。

测试探针 `tests/openwrt/geodata-probe.go` 仅用于验证，不随用户安装包交付。
复现时在 wing 中编译，设置 `DAED_TEST_GEODATA_PROBE` 后运行 Python 测试。
规则解析验证没有创建控制平面，也没有加载 eBPF 或改变宿主网络。
R4S 上的真实 eBPF、DNS、LAN 流量及长期运行仍待升级后实机验收。

## 订阅下载修复

用户路由器只读诊断：同一条订阅，系统路径的 Daed / PassWall 请求头均得到
403 / AUTH_FAIL，经已运行 PassWall 的本机 SOCKS 则得到 HTTP 200、Base64、
72 条节点链接；另一条订阅在三种路径下均成功。这定位到可用下载出口差异，
并不表明改 User-Agent 就能修复。

新增自动回退，沿用原有系统路径和 dae 路由，失败后读取 PassWall 当前的回环
SOCKS 地址重试。DNS 由 SOCKS 出口处理，HTTPS 保留证书验证。可选 `passwall`
模式只用该出口，`off` 保留原路径。没有 PassWall 时不影响原本成功的下载。
不修改数据库结构、订阅链接或其他代理服务配置，无新增 npm / Go 依赖。

- 56 项 Python 测试：隔离 OpenWrt rootfs 内运行真实 BusyBox/UCI/jsonfilter/
  ucode/rpcd/APK。新增 5 项下载出口发现测试；ShellCheck 与 8 项 LuCI 脚本测试。
- x86_64 / ARM64 静态程序；22 个原生 IPK/APK，检查每个包的架构、依赖、脚本、
  权限和新下载助手文件。R4S APK 使用 `aarch64_generic`，不强制忽略内核 ABI。
- 原生 LuCI / rpcd / uhttpd 浏览器回归：旧版数据升级、群组绑定、节点操作、

源代码以固定子模块加 `openwrt/wing/` 增量保存，构建时先执行
`python3 openwrt/prepare-wing.py wing`。工具校验原文件哈希，记录生成文件摘要，

此版本仍是测试版。隔离测试没有访问用户真实订阅，也未远程修改用户路由器。

## 管理面板改版

- 群组、节点、订阅置于常用功能区；配置、DNS、路由仍使用原有编辑器，折叠
  后保持挂载；流量概况与趋势保留 1 分钟、10 分钟、30 分钟、1 小时时间范围。
- 节点库合并手动节点和订阅节点，按 ID 去重，新增搜索、来源筛选、延迟排序、
  分批显示及加入群组。订阅节点保留订阅的管理边界，不提供手动编辑或删除。
- 延迟展示实际测速结果与时间；未测速不显示虚构数值。默认群组标签不冒充
  当前实际路由选用状态。运行状态、变更状态和流量数据均来自现有后端。
- 保留节点导入和协议编辑、二维码、敏感链接遮盖、删除确认、订阅更新与定时
  更新、名称过滤、群组成员选择及拖拽。失败时保留导入/编辑输入，提供重试。
- 修复节点编辑原标签未预填，以及普通 VLESS 编辑生成 `flow=none` 后被 dae
  拒绝的问题；实际保存回归覆盖原协议、地址和标签。
- 节点批量导入遇到无效链接时回滚，避免部分写入后表单误报成功。批量订阅
  更新等待全部请求结束，部分失败时仍刷新列表以反映已完成的结果。
- LuCI 仍只保留管理面板和运行日志，使用已有 LuCI 会话和同源 CGI 网关。
  不增加依赖、不修改 wing 子模块，不变更节点、订阅、配置的数据结构。

- 使用真实 API 验证来源筛选、搜索空结果、只读订阅节点、加入群组及重复防护。
- 使用键盘执行筛选后拖拽排序，验证隐藏节点次序不被改变。
- 本地订阅源返回 HTTP 503 时更新失败，原节点不丢失；恢复后重试成功。

## 复现浏览器升级测试

需要 Linux root、预先校验并安装完整 LuCI 的隔离 rootfs、旧/新运行程序及
新网关。测试只写入专用 `--workspace`，目录必须不存在；可用 JSON 控制命令
停止服务。Windows 浏览器端使用项目现有 Playwright，未增加依赖。

```sh
python3 tests/openwrt/native_panel.py --rootfs /path/to/rootfs \
  --old-runtime /path/to/0.2.1/daed --runtime /path/to/0.3.0/daed \
  --proxy /path/to/0.3.0/luci-proxy --workspace /path/to/new-test-directory \
  --control /path/to/shared-control
DAED_PANEL_CONTROL=/path/to/shared-control node tests/openwrt/browser-panel.cjs
```

可用 `DAED_BROWSER_EXECUTABLE` 指定浏览器。HTTP 端口 18080，HTTPS 18443，
订阅源 18081，内部 API 12025。夹具为测试身份和本地订阅，不使用真实代理凭据。

## 边界
